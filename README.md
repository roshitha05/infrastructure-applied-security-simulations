# Infrastructure Applied Security Simulations

A collection of hands-on cybersecurity exercises focused on infrastructure security, networking, authentication, cryptography, service enumeration, and common attack techniques.

This repository documents practical security simulations completed in controlled lab environments as part of my cybersecurity studies and independent learning. The project focuses on applying theoretical security concepts through practical exercises and documenting the results clearly.

## Overview

The exercises in this repository explore different areas of infrastructure and system security. Each section contains practical work relating to a specific security topic.

The repository is organised into the following areas:

- **Authentication** — authentication mechanisms, credentials, access control, and authentication-related security concepts.
- **Command and Control** — command-and-control concepts and related security behaviours.
- **Cryptography** — practical exercises involving cryptographic concepts and data protection.
- **Network Layer** — network protocols, traffic behaviour, and network-level security concepts.
- **Service Enumeration** — identifying exposed ports, services, and system information during infrastructure assessment.

## Ethical Use

The material in this repository is intended strictly for educational purposes and authorised security testing environments.

Any security techniques demonstrated in this project should only be performed on systems where explicit permission has been granted.
